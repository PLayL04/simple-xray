SimpleVpn — простой клиент для подключения к серверу администратора
=====================================================================

Установка
---------
1. Распакуйте архив в папку, где у вас есть права на запись, например в «Документы» или на рабочий стол.
   Не распаковывайте в «Program Files».
2. Запустите SimpleVpn.exe.
   Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
   Это предупреждение появляется потому, что у программы нет платной цифровой подписи.
   Антивирус может проверять программу при первом запуске 10–20 секунд.
3. Нажмите «+» и вставьте ссылку vless://, которую прислал администратор.
   Ещё можно открыть картинку с QR-кодом или найти QR-код на экране.
4. Нажмите большую кнопку — готово.

Как пользоваться
----------------
• Крестик окна не закрывает программу: она остаётся у часов (значок может прятаться под стрелкой «^»).
  Чтобы выйти, щёлкните значок правой кнопкой и выберите «Выход».
• «Маршрутизация» на главном экране выбирает, какие сайты идут через сервер.
  По умолчанию — «Всё, кроме RU»: российские сайты открываются напрямую.
• В настройках можно включить запуск вместе с Windows и автоматическое подключение.
• Режим «VPN (TUN)» в настройках пропускает через сервер весь трафик, включая игры.
  Для него нужны права администратора: программа перезапустится и Windows спросит разрешение.

Если что-то не работает
-----------------------
Настройки → Дополнительно → «Показать журнал» → «Копировать». Отправьте текст администратору.
Ключи доступа в журнал не пишутся.

Обновление
----------
Закройте программу (значок у часов → «Выход») и распакуйте новый архив в ту же папку с заменой файлов.
Папка data с вашими серверами и настройками сохранится.
